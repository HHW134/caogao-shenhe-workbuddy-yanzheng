# 术语章节审核器使用说明

## 文件说明

- `术语章节审核器.py`：主程序，实现术语章节自动化审核。
- `测试样例.json` / `测试样例_正常.json`：示例输入文件。
- `测试结果.json` / `测试结果_正常.json`：示例输出文件。

## 审核规则覆盖

基于 `术语审核规则.json`，当前审核器覆盖以下规则：

1. **术语双语检查**：中文术语必须对应英文，英文术语必须对应中文。
2. **英文术语格式**：英文术语必须全小写，仅允许小写字母、空格、连字符、下划线、斜杠。
3. **引导语格式**：必须为三种标准形式之一，或“本文件没有需要界定的术语和定义”。
4. **引导语位置**：必须能够定位到引导语段落。
5. **引导语冗余**：引导语只能有一句话，不能包含多余内容。
6. **无术语引导语**：无术语时必须使用指定说明。
7. **术语独占一行**：术语名称不能和定义在同一行。
8. **缩略语分号**：定义中括号说明的缩略语前需用中文分号“；”分隔。
9. **定义中不重复术语**：具体术语名称不应在定义中重复出现。
10. **条款约束**：定义中不能包含“应、宜、可、应该、建议、可以、不应、不准许、无须”。
11. **禁用开头词**：定义不应以“系指、是指、指、是”开头。
12. **正文使用统计**：中文术语在正文中出现次数≤1时建议删除。
13. **章节名称**：检查章节名称是否规范，是否存在结构错误。
14. **子章节结构**：当章节为“术语、定义和缩略语”时，子章节必须恰好为“术语和定义”和“缩略语”。

## 命令行用法

### 1. 审核 JSON 文件

JSON 文件格式如下：

```json
{
  "paragraphs": [
    "术语和定义",
    "下列术语和定义适用于本文件。",
    "示例术语 example term",
    "示例术语用于演示。"
  ],
  "full_text": "这是一份测试文档。示例术语出现在这里。"
}
```

也可以只传入段落数组：

```json
[
  "术语和定义",
  "下列术语和定义适用于本文件。",
  "示例术语 example term",
  "示例术语用于演示。"
]
```

运行：

```bash
python 术语章节审核器.py 测试样例_正常.json -o 输出结果.json
```

### 2. 审核 docx 文件（含批注回写与 xlsx 汇总）

需要安装 `python-docx` 与 `openpyxl`：

```bash
pip install python-docx openpyxl
```

运行（默认在源文件旁生成两个文件）：

```bash
# 默认：在同目录生成 <文件名>_术语审核批注.docx 与 <文件名>_术语审核问题.xlsx
python 术语章节审核器.py 文档.docx

# 显式指定输出路径
python 术语章节审核器.py 文档.docx \
    --docx-out 文档_术语审核批注.docx \
    --xlsx-out 文档_术语审核问题.xlsx \
    -o 结果.json          # 可选：额外导出 JSON 结果
```

**输出两个文件**：

1. **带批注的 docx**（`<文件名>_术语审核批注.docx`）
   - 审核时找到的每个问题，以 Word **批注（comments）** 形式插入源文档对应段落。
   - 批注内容含：`【审核要点】[级别]`、问题说明、修改建议、命中详情。
   - 不会覆盖原文档，生成独立副本；原文档结构、样式、正文均保持不变。
2. **审核问题汇总 xlsx**（`<文件名>_术语审核问题.xlsx`）
   - `概览` 工作表：章节标题、引导语、术语条目数、子章节、问题总数、审核结论。
   - `审核问题` 工作表：序号、审核要点、级别、问题描述、修改建议、位置、详情、段落索引；
     按级别着色（error 红 / warning 黄 / info 蓝），含筛选与冻结表头。

**其他参数**：

- `--no-comments`：仅生成 xlsx，不向 docx 写批注。
- `-o/--output`：额外导出 JSON 结果（与旧版一致）。
- `--title`：手动指定章节标题（默认自动检测）。

> 说明：批注锚定依赖解析得到的段落索引；若某问题无法定位到具体段落（如章节级结构问题），仍会进入 xlsx，但不写批注。

### 3. Python API 调用

```python
from 术语章节审核器 import audit_terminology

paragraphs = [
    "术语和定义",
    "下列术语和定义适用于本文件。",
    "示例术语 example term",
    "示例术语用于演示。",
]
full_text = "这是一份测试文档。示例术语出现在这里。"

issues = audit_terminology(paragraphs, full_text=full_text)
for issue in issues:
    print(issue.to_dict())
```

## 输出格式

输出为 JSON，包含：

- `章节标题`：检测到的术语章节标题。
- `问题总数`：发现的问题数量。
- `问题列表`：每条问题的详细信息。
  - `审核要点`：对应规则分类。
  - `位置`：问题所在位置。
  - `问题`：问题描述。
  - `修改建议`：修改建议。
  - `级别`：error / warning / info。

## 注意事项

1. 当前解析器基于段落文本和正则启发式，实际文档格式可能更复杂，建议结合人工复核。
2. `full_text` 用于统计术语在正文中的使用次数，若未提供则跳过该规则。
3. 对于“术语、定义和缩略语”章节，子章节标题必须严格为“术语和定义”和“缩略语”。
